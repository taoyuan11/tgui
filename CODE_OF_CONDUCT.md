# Code of Conduct

This project follows a simple contributor code of conduct.

## Expected behavior

- Be respectful and specific.
- Assume good intent, but listen when someone says a comment or action caused
  harm.
- Focus reviews on code, behavior, tests, documentation, and user impact.
- Make space for different experience levels and platform backgrounds.

## Unacceptable behavior

- Harassment, threats, or personal attacks.
- Sexualized language or imagery in project spaces.
- Repeated disruption of issues, reviews, or discussions.
- Publishing private information without permission.

## Enforcement

Maintainers may edit, hide, or delete comments; close discussions; request
changes in behavior; or block participation when needed to keep the project
usable and safe.

Report concerns privately to the maintainer email listed in `Cargo.toml`.
